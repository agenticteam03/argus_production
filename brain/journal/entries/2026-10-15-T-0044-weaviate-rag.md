## 2026-10-15 — T-0044 step 1: hybrid runbook retrieval in a local Weaviate behind KnowledgePort (ACR-0015 applied, 1.8.13)

Type: implementation + architecture
Who: conantkd (+ agent)
Context: RAG with a vector database is a technical requirement of the project. ACR-0015 (juanes6554) was accepted in
#155 after a capacity trial on vm-095 (Weaviate 44 MiB idle, 210 MiB peak with 6,510 objects, hybrid queries p95 about
30–60 ms, Argus `/healthz` worst 9 ms, I/O pressure 5 %; removed afterwards).
Decision / result: `argus/adapters/outbound/rag.py` adds the embeddings (OpenAI dialect, and a keyless hashing one for
tests), a thin Weaviate REST/GraphQL client and `HybridRunbooks`. Weaviate ranks with its native hybrid query, filtered to
the class's runbooks; the passage text always comes from the library, matched by SHA-256; any failure falls back to
TF-IDF. `ARGUS_RETRIEVAL` selects it (`tfidf` default), `argus runbooks index|search [--compare]` builds and probes
the index, and `argus-v18-weaviate` joins `compose.core.yml` (no host port, 512 MiB, no vectorizer or API modules).
`ARCHITECTURE.md` §3.5, §15.3, §16.1 and §21.2 updated, version 1.8.13.
Consequences: nothing changes on the VMs until step 2; the worker stays on TF-IDF until the comparison. The query is
embedded at every recall (class, detector findings, reason), by the same provider and key as the model. The §21.2
replay pins `tfidf`.
References: [ACR-0015](../../architecture/changes/ACR-0015-rag-hybrid-retrieval.md),
[T-0044](../../tasks/current/T-0044-rag-pgvector.md).

Steps 2–3, same day: on vm-095 (branch deployed, both leases) `argus-v18-weaviate` holds 630 indexed sections and
answers every hybrid query; a section-level comparison on 44 cases (labels by class) shows the hybrid better where
TF-IDF fails (disk, blind spot) and worse where it works (restart loop, dependency, CPU). TF-IDF stays the default;
sections are now embedded with their runbook title, and the title stubs can be skipped (`ARGUS_RETRIEVAL_SKIP_TITLES`).
vm-095 stays on this branch with Weaviate running until the merge and an AFTER-MERGE.
